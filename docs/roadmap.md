# Roadmap

This is a plan, not a description of what already exists. Everything listed here
is **not yet built** unless it also appears as a shipped feature in the root
README.

## Near term

- **Broaden coverage.** Fill the currently empty categories (Workflow
  Orchestration, Data Quality, Data Observability) with strong, verifiable
  build-it-yourself resources.
- **More learning paths.** Add paths for search engines and for vector search /
  retrieval.
- **Deploy the site.** Publish to GitHub Pages and add the live URL to the README
  Demo section (see [deployment.md](deployment.md)).

## Medium term

- **Content translations.** Optionally translate entry summaries into Traditional
  Chinese, keeping English as the canonical source.
- **Feed consumers.** Document the JSON feed format for third-party tools and add
  a JSON Schema for it.
- **Richer relationships.** Let entries declare prerequisite entries (by slug) so
  the site can suggest an order automatically.

## Longer term / ideas

- A "study plan" export (e.g. a printable checklist) built from a learning path.
- Community voting or "I built this" counts — only if it can be done without
  collecting personal data or adding a backend.

## Non-goals

- No accounts, no user database, no server runtime.
- No analytics, advertising, or third-party tracking.
- No relicensing or rehosting of third-party resources; we only ever link to
  them.

Have an idea? Open an issue — see [CONTRIBUTING.md](../CONTRIBUTING.md).
